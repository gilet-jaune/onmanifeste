# Fiches mémo Signal à imprimer

Trois fiches d'**une page A4** tirées du guide [Groupes Signal](../guides/groupes-signal.md) : membre, arrestation ou groupe compromis, rôles d'organisation.

!!! warning "Ne les remplissez pas"

    Ces fiches ne contiennent **aucun nom, numéro ni lieu** : n'en écrivez pas dessus. Les noms de militant·es et le point de repli se **retiennent**, ils ne s'écrivent pas. Évitez l'imprimante partagée d'un lieu de travail, qui garde souvent un journal des impressions.

## Fiche 1 : membre d'un groupe Signal

- **Rien d'illégal par écrit** : pas d'appel à la violence ni aux dégradations, pas de menace, même pour rire. Le sensible se dit **en vrai, sans téléphone**.
- **Pas de messages vocaux** : votre voix vous identifie. Écrivez.
- **Liens** : supprimez tout ce qui suit le `?` avant de partager.
- **Photos** : floutez les visages. Pas de vrais noms, d'adresses ni de captures d'écran.
- **Pas de localisation en direct** : un rendez-vous se donne en vrai.
- **Besoin d'aide ?** Nommez une personne. **Urgence** : **15** ou **112**, pas le groupe.
- **Un doute sur quelqu'un** : les **RH**, en privé. Jamais d'accusation dans le groupe.
- **Ne partagez jamais** le lien ni le code QR d'un groupe sas, de confiance ou d'un sous-groupe. Seul le lien du groupe public se partage.
- **À retenir, sans l'écrire** : le nom de militant·e de votre secrétaire ou d'une personne des RH, et un **point de repli** convenu de vive voix.
- **Libellé de rôle** : seulement un rôle de manif (medic, legal…), jamais un rôle d'organisation.

</section>

## Fiche 2 : arrêté·e, téléphone perdu, groupe compromis

**Si vous êtes arrêté·e ou perdez votre téléphone**

1. **En garde à vue, ne parlez de personne** : vous avez le droit de garder le silence, et rien ne vous oblige à parler des autres ni de vos groupes.
2. **Prévenez les RH** dès que possible, en vrai ou par un·e camarade : vous serez retiré·e des groupes par précaution, rien de personnel.
3. **Récupérez votre compte** sur un autre téléphone (numéro et code PIN), puis supprimez les **appareils associés** inconnus.
4. **Au débrief, dites tout** : téléphone pris, déverrouillé, code donné, temps hors de votre vue. Ce n'est pas une faute.

**Si on vous retire d'un groupe**

- **Pas de panique** : c'est souvent une précaution.
- **Ne quittez pas un groupe de vous-même** s'il semble compromis : attendez la consigne.
- **Ne créez pas de groupe de remplacement** ; allez au point de repli ou contactez les RH.
- **N'acceptez une invitation que d'un·e gardien·ne ou d'un·e secrétaire que vous connaissez** ; dans le doute, vérifiez en vrai.

**Si le groupe est compromis**

- Quelqu'un se fait embarquer ou perd son téléphone → **retrait conservatoire, tout de suite**.
- Inconnu dans le groupe, fuite, doute sérieux → **procédure « groupe compromis »** : si l'on sait par où ça fuit et que c'est retiré, le groupe continue ; sinon, **on déménage**.

</section>

## Fiche 3 : rôles d'organisation

Les rôles **tournent** ; personne n'a tous les rôles, et aucun groupe ne réunit toutes les personnes clés.

| Rôle | Il ou elle fait | Il ou elle ne fait pas |
| --- | --- | --- |
| **Recruteur·se** | Parle du mouvement, oriente vers le groupe public et les groupes sas | Valider ; être garant·e de ses recrues ; noter quoi que ce soit sur elles |
| **Secrétaire** | Coordonne la rencontre, **valide** quand les conditions sont réunies, nettoie le groupe sas et y ajoute les RH | Valider sans garant·e ; **ajouter** au groupe de confiance ; tenir une liste de présence |
| **RH** | Second contrôle, **ajoutent** au groupe de confiance, reçoivent les doutes, décident des retraits **à deux**, {{ default("decision_delay") }} après une pause préventive | Organiser les groupes sas ; décider seul·e d'un retrait |
| **Gardien·ne** | Veille sur la configuration du groupe (au moins deux par groupe), signale aux RH les arrivées étranges | Ajouter quelqu'un de non validé ; partir en action avec son téléphone de gardien·ne |
| **Modération** | Rappelle la charte, recadre en privé | Accuser quelqu'un dans le groupe |

</section>
